# Task_7 – Sales_Data.DB Summary using Python & SQLite

For this task, I created a small database of sales records using SQLite inside Python.

I first made a table called `sales` with columns for product name, quantity, and price. Then, I inserted more than 20 sample records manually using Python.

After that, I wrote a SQL query to group the products and calculate total quantity sold and total revenue. I ran this query from Python using pandas, and stored the result in a DataFrame.

Finally, I used matplotlib to create a simple bar chart showing the revenue for each product.

Everything was done inside a Jupyter Notebook and the chart was saved as an image too.
